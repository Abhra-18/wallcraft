# 🎨 Wallcraft — Premium Wallpaper Website

A stunning wallpaper browsing website for desktop and mobile, powered by the **Pexels API**.

## ✨ Features

- **Dark premium theme** with glassmorphism and gradient accents
- **Desktop & Mobile toggle** — switch between landscape and portrait wallpapers
- **Search** with instant results
- **Category navigation** — Explore, Nature, Abstract, Minimal, Dark, Space
- **Color filters** — filter by dominant color
- **Masonry grid layout** with lazy-loaded images
- **Full preview modal** with photographer info and multiple download sizes
- **Infinite scroll** for continuous browsing
- **Fully responsive** across all screen sizes
- **Quick download** from card hover

## 🚀 Getting Started

1. Get a free API key from [pexels.com/api](https://www.pexels.com/api/)
2. Open `index.html` in your browser
3. Paste your API key in the welcome modal
4. Browse, search, and download wallpapers!
